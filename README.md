# Bella Monopoly

Game cờ tỷ phú 3D chạy trên web — React Three Fiber, Zustand, Tailwind.

```bash
npm install
npm run dev        # dev server
npm test           # Vitest
npm run typecheck
npm run simulate -- --seed 42   # giả lập 1 ván 4 người, in log
npm run build
```

- Luật chơi: [docs/GDD.md](docs/GDD.md)
- Quy tắc kiến trúc & quy ước code: [CLAUDE.md](CLAUDE.md)

## Asset

Model 3D và âm thanh của [Kenney](https://kenney.nl) (CC0): Mini Characters, Cube Pets, City Kit Suburban, Interface Sounds. Giấy phép đi kèm trong `public/models/*/LICENSE.txt` và `public/sounds/LICENSE.txt`.
